# Changelog

## 0.2.0 - 2026-09-05

- Added the preregistered v1.1 external validation on the Yearbook stream at delays 10, 50, and 100 and on the naturally delayed Criteo conversion stream.
- Added all 256 completed trial records, the 240-row analysis table, frozen configuration, provenance, paired intervals, and terminal YELLOW decision. Data and third-party source trees remain excluded.
- Established that rank-four global SVD reduced per-event credit state 6.35-fold while preserving exact-credit performance and median gradient cosine in every audit cell.
- Recorded the competitive boundary: global SVD did not beat equal-byte replay or random projection at two independent conditions, and it had unfavorable end-to-end throughput.
- Added a dated novelty audit that distinguishes delayed-credit storage from RTRL approximation, classical eligibility traces, gradient communication compression, and generic matrix sketching.
- Reframed the manuscript outline around compression fidelity, learning utility, and systems cost.
- Added an independent verifier and continuous-integration coverage for the external-validation code and frozen result decision.
